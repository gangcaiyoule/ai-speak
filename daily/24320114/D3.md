## 遇到的问题与解决

1. Gitee 创建新 Issue 时 Milestone 字段返回为空，使用 Issue 更新接口补设时返回 500。保留 Issue 正文中的 M2 信息，并在 PR 创建时成功设置 `milestone_number=228162`，没有伪称 Issue Milestone 已生效。
2. PR !17 初次创建后，Gitee 双向关联列表为空。按照仓库 `gitee-pr` skill 补写 `Closes #IKD3DO` 并设置 `close_related_issue=1`，重新读取后确认 PR 和 Issue 两端均已关联。
3. Repository 初版读回报告时没有重建 Finding、证据引用和优先行动，无法满足完整读回要求。追加 `loadFindings` 和优先行动查询，并重新执行 Go 测试、静态检查和构建。
4. 当前 migration 表使用源会话、问题和回答的 UUID，尚未与完整练习会话表建立跨模块外键；该部分依赖练习模块后续实现，已在 PR !17 的已知限制中说明。
