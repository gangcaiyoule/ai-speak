# 课程思政报告

## 一、项目选题与现实责任

SpeakUp 面向英语学习和求职表达场景，目标是帮助学习者在缺少语言环境时获得持续练习机会。我负责场景选择与练习准备模块，在设计过程中关注的不只是功能能否运行，还关注功能是否真正回应学习者的需要。场景内容需要贴近岗位面试、IELTS 和职场沟通等真实任务，练习目标需要由用户自己设定，系统则负责把目标转化为清晰的练习步骤。

## 二、技术实践中的价值判断

我在设计中坚持用户数据隔离和最小必要原则。计划、会话、问题和回答都绑定登录用户，接口会拒绝越权访问；场景版本和会话快照被保留下来，避免历史练习内容被后续配置变化无意修改。对于 AI 功能，我把它定位为辅助练习和反馈工具，用户仍然是目标设定和结果判断的主体，模型生成内容不能替代人的思考。

我还坚持错误尽早暴露。空回答、重复回答、非法状态转换和数据库连接失败都会返回明确错误，而不是静默忽略或自动修改。这样做既便于用户理解，也便于开发者定位问题，体现了对软件质量和使用者权益的负责态度。

## 三、团队协作与工程伦理

我通过 Issue、分支、Commit 和 Pull Request 留下可追溯记录，明确场景准备、实时语音和评测复盘的职责边界。遇到冲突时，我优先沟通接口和数据结构，保留主干已有成果，不覆盖其他成员的工作。测试通过与否、Flutter SDK 未安装等限制均如实记录，不把未执行的命令写成已完成结果。

## 四、个人成长与社会责任

本次实践让我认识到，软件工程师不仅要实现功能，也要考虑隐私、安全、可解释性和社会影响。教育类产品尤其需要尊重学习者的差异，不能用单一分数简单定义一个人的能力。今后我会继续学习技术，同时保持诚实记录、尊重用户、服务真实需求的工程态度。

## 五、个人、集体与国家发展的联系

项目实践让我认识到，个人能力提升并不是孤立的。个人能否完成可靠的模块，会直接影响小组整体交付；小组能否形成稳定的软件产品，又关系到项目是否能够服务真实用户。SpeakUp 选择英语口语训练作为主题，是因为国际化交流能力已经成为计算机专业学生持续学习和参与工程实践的重要基础。通过把个人负责的页面、接口和数据模型做好，我既是在完成课程任务，也是在为团队产品和未来的技术交流能力打基础。

从更大的角度看，人工智能和软件工程正在影响教育、就业和公共服务。国产软件和人工智能工具与国际产品相比仍有提升空间，学生需要正视差距、学习先进方法，同时形成自主分析和自主实现能力。项目中我使用成熟框架提高效率，但没有把工具输出直接当作最终答案，而是通过阅读代码、运行测试和人工检查确认结果。只有掌握核心原理，才能在关键技术上逐步形成自主能力，为科技进步贡献力量。

## 六、诚信与实事求是

课程明确要求报告和代码独立完成，这使我更加重视过程证据。每次提交前，我会核对改动范围、提交作者、测试命令和实际输出；没有安装 Flutter/Dart SDK 时，我明确写出未执行的检查，不把推测结果写成事实。文档中的功能描述以仓库代码、日报和接口实现为依据，遇到尚未完成的语音、评测能力则标注为后续范围。

在使用 AI coding agent 时，我把它当作阅读和讨论工具。对于生成的代码，我会检查命名、边界条件、错误处理和与现有接口的兼容性；对于生成的文字，我会根据自己的实际工作重新核对和改写。这样的过程虽然需要额外时间，却能避免抄袭和不负责任的技术传播，也让我真正理解交付物。

## 七、敬业、友善与团队协作

集中实践时间有限，团队成员必须服从共同进度安排。我按照既定 Issue 拆分任务，及时同步接口变化，在合并前处理冲突，并在需要时帮助队友理解认证、场景和会话之间的调用关系。讨论中我尽量用具体的请求示例、状态图和错误码表达意见，减少只凭感觉争论。对于队友的实现，我先理解其设计目的，再提出可验证的改进建议。

友善协作并不意味着回避问题。发现接口字段不一致、状态转换不完整或测试覆盖不足时，我会及时指出，并和相关成员一起确认修复方式。通过这种方式，团队既能保持融洽，也能维护工程质量。团队协作让我体会到，个人优秀不能替代整体配合，可靠的交付来自每个人对共同目标的持续负责。

## 八、严谨态度与工匠精神

练习准备模块包含许多看似细小的规则，例如场景详情版本必须一致、归档计划不能再次创建会话、回答必须对应当前问题、重复提交要被拒绝。这些规则如果被忽略，用户可能会看到错误的练习内容，历史数据也可能失去可信度。因此我把需求拆成可检查的状态转换和测试用例，逐项验证正常和异常路径。

调试时，我先复现问题，再查看日志、请求数据和状态变化，最后修改最接近根因的位置。对于空列表、UUID 格式、用户权限和数据库约束等问题，我没有用静默兜底掩盖，而是让系统返回清晰错误。持续打磨这些细节，培养了我严谨、耐心和精益求精的工作习惯。

## 九、终身学习与国际视野

项目同时涉及 Flutter、Go、PostgreSQL、OpenAPI 和 Git 协作，这些技术需要通过文档阅读、示例验证和实际调试不断学习。遇到不熟悉的接口或库，我会先确认官方行为，再结合项目上下文选择实现方式。英语口语陪练项目本身也提醒我，计算机专业学习不能停留在本地课堂，要能够阅读英文技术资料、理解国际开发规范，并面向跨文化用户清晰表达技术方案。

今后我会继续补足移动端测试、数据库性能和实时音频方面的知识，关注国内外人工智能教育产品的发展，在比较中发现差距，在实践中提升自主能力，把个人成长与团队发展、社会需求和国家信息产业进步联系起来。
