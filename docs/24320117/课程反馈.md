# 课程反馈

## 我完成的工作

我负责 SpeakUp 项目的场景选择与练习准备模块。立项时，我参与分析英语学习者在真实语境、练习目标和持续复练方面的需求，并与队友讨论模块边界；设计阶段，我梳理了场景、角色、练习模式、计划、会话、问题和回答的数据模型，设计了接口、错误码和状态机；实施阶段，我完成了 Flutter 场景选择与准备页面、Go 服务端接口、内存和 PostgreSQL 数据访问、数据库迁移、OpenAPI 契约、单元测试和联调记录。我还处理了场景版本校验、用户隔离、空列表、重复回答、非法状态转换等问题，并通过 Issue、分支、Commit 和 Pull Request 维护协作过程。对测试和环境限制，我都按实际情况记录。

## 对课程和引入 AI 的感受与建议

课程把需求、设计、编码、测试、协作和答辩串成了完整过程，让我感受到软件开发不仅是把代码写出来，还要能解释设计选择、证明运行结果并承担维护责任。AI coding agent 能帮助我快速阅读代码、整理思路和发现边界情况，但需求取舍、接口确认、代码审查、测试判断和最终责任仍然属于人。建议课程继续保留现场解释和随机改动环节，同时提供 AI 使用记录模板，让学生记录提示词、采纳或修改的内容、验证方法和个人反思；还可以增加一次跨模块联调演练，使大家更早发现接口不一致和协作流程中的问题。
