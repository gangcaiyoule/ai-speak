# D4 Ticket 拆分与执行清单

## 1. 使用方式

本清单只用于拆分今天的开发任务，不代表代码已经实现，也不代表远端 Gitee Issue 已经创建。

仓库协作层级如下：

```text
Issue（需求范围与验收结果）
  └── Ticket（具体执行任务）
        └── Commit（一次可解释的代码变更）
              └── PR（Issue 的最终交付）
```

今天暂定拆成 3 个 Issue、12 个 Ticket。每个 Issue 都应有独立范围、独立验收标准和独立分支；Ticket 是开发时的检查清单。

## 2. Issue 一：练习计划与准备流程

### 目标

让用户能够从已有场景选择结果进入练习准备页，填写练习目标并创建、查看、归档自己的练习计划。

- [ ] 确认计划请求和响应字段；
- [ ] 确认 `scene_id`、`scene_version`、`role_id` 和 `practice_option_id` 的含义；
- [ ] 确认计划状态：`DRAFT`、`ACTIVE`、`ARCHIVED`；
- [ ] 更新 `api/modules/` 中的 OpenAPI（开放接口）契约。

### Ticket 1.2：实现计划领域模块

- [ ] 定义 `PracticePlan` 模型；
- [ ] 定义 Service Interface（服务接口）和 Repository Interface（仓储接口）；
- [ ] 实现目标文本校验和场景版本校验；
- [ ] 实现内存 Adapter（适配器）供单元测试使用。

### Ticket 1.3：实现计划 PostgreSQL 持久化

- [ ] 新增 `practice_plans` 表；
- [ ] 增加用户、状态、时间和场景字段约束；
- [ ] 增加用户和状态相关索引；
- [ ] 实现 PostgreSQL Repository；
- [ ] 验证迁移可重复执行且不会重复应用。

### Ticket 1.4：暴露计划 HTTP 接口

- [ ] 实现创建计划；
- [ ] 实现当前用户计划列表；
- [ ] 实现计划详情；
- [ ] 实现归档计划；
- [ ] 返回统一的参数错误、鉴权错误、越权错误和资源不存在错误。

### Issue 1 验收

- [ ] 登录用户能够创建计划；
- [ ] 计划中保存完整场景选择和练习目标；
- [ ] 用户只能查看自己的计划；
- [ ] 归档后不能创建新的练习会话；
- [ ] Go 测试覆盖成功、参数错误、越权和归档边界。

## 3. Issue 二：练习会话与文本回答

### 目标

让用户能够从练习计划创建会话，依次回答场景问题，并完成会话。

### Ticket 2.1：定义会话状态机

- [ ] 定义 `DRAFT`、`ACTIVE`、`COMPLETED` 状态；
- [ ] 只允许 `DRAFT -> ACTIVE -> COMPLETED`；
- [ ] 拒绝重复激活、已完成后回答和已完成后再次完成；
- [ ] 为每种非法转换定义错误码。

### Ticket 2.2：实现问题快照生成

- [ ] 在创建会话时读取场景的 `turn_blueprints`；
- [ ] 保存问题文本快照和顺序；
- [ ] 保存会话使用的场景版本；
- [ ] 不接入 LLM 或 Agent 动态出题。

### Ticket 2.3：实现会话内存 Adapter 和 Service

- [ ] 实现创建会话；
- [ ] 实现查询会话详情；
- [ ] 实现激活会话；
- [ ] 实现提交文本回答；
- [ ] 实现当前问题推进；
- [ ] 实现完成会话。

### Ticket 2.4：实现会话 PostgreSQL 持久化

- [ ] 新增 `practice_sessions` 表；
- [ ] 新增 `practice_questions` 表；
- [ ] 新增 `practice_turns` 表；
- [ ] 增加外键、状态、问题顺序和回答唯一性约束；
- [ ] 使用事务保证回答保存与当前问题推进的一致性。

### Ticket 2.5：暴露会话 HTTP 接口

- [ ] 实现创建会话；
- [ ] 实现查询会话；
- [ ] 实现激活会话；
- [ ] 实现提交文本回答；
- [ ] 实现完成会话；
- [ ] 所有接口从 Bearer Token（Bearer 令牌）解析用户身份，不接受客户端传入 `actor_id`。

### Issue 2 验收

- [ ] 能从有效计划创建会话；
- [ ] 会话能生成有序问题；
- [ ] 只有当前用户能访问会话；
- [ ] 只有激活会话能提交回答；
- [ ] 回答后能推进到下一题；
- [ ] 最后一题完成后会话进入 `COMPLETED`；
- [ ] 非法状态转换返回稳定错误码。
